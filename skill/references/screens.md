# 每一屏的配方和例子

SKILL.md「使用步骤」给形状，这里给完整例子和脚本命令。例子里的数字全是 2026-10-16 作者本机实跑出来的（那天这个会话读不到 Claude，正好示范「读不到」的写法）。四条取舍：一场只出一张面板，放开场；每屏都有默认答案，沉默就按默认跑；必须等答复的点只有四处（功能地图分档、开不开工、取舍类争议、质量优先且额度不够）；面板不超过 14 行、80 列，排活表每件一行，超过 8 件折成「前 8 件 + 另 N 件同类」。

读法：「件」是标准件，1 件 = 一条页面实现类、6.1 Sol / high 或 Sonnet 做的执行线（约 3.5 万 token）；「约」表示系数还没校准，旁边一定有百分点；「？」表示接上了但读不到额度，不进合计；Grok 仅「试新型号」开且已登录时可试派取证、复核只读活；Claude 读不到时按紧处理，常驻活退回 Codex 侧。Claude 读到宽或正常时，分配预览写「取证、批量 Haiku；复核 Sonnet 只读」；读到空时常驻活仍退回 Codex。

试新型号开且 Grok 已登录时，分配预览在项目指令前多一行「试用 Grok：取证、复核（只读，记战绩）」。关着或未登录时不出现，自动起步表不变。

这条消息里还要有：这次走哪种用法、为什么、题目一句人话；有新版本提醒一句；第一次用问一次回传。要问的合成一次问，没有就直接往下。主席回车或不答 = 自动分配；说「质量优先」「省着用」「赶时间」只管本场，记账本「主席指令」。单家模式（本机没有 Codex）面板 Codex 行写「读不到（本机没有 Codex） → 单家模式」，预览写「审稿 Fable 子代理（同家）」。

## 纪要 + 排活表

拆分表先写进 plan §10（列头见 plan-template），然后：

```bash
python3 scripts/schedule.py --plan plan.md --strategy auto --probe rounds/probe.json --start 15:00 > rounds/schedule.md
python3 scripts/schedule.py --plan plan.md --strategy auto --probe rounds/probe.json --start 15:00 --json > rounds/schedule.json
```

把 `rounds/schedule.md` 原样贴进纪要的「排活表」一段：

```

 1  数据层：账目模型与存储  Codex 的 Astra · 高    跨模块、后面三页都靠它  1h43   17:12     Codex 的 6.1 Sol 只读  无
 2  首页和「记一笔」样张    我                     视觉判断 Codex 做不好   37 分  15:58     你点头                 无
 3  「记一笔」页面          Codex 的 6.1 Sol · 高  照样张做，规格清楚      31 分  16:58     Codex 的 Astra 只读    2

 6  合并三条线、全量回归    Codex 的 6.1 Sol · 高  合并后整包跑测试        1h34   19:24     我在主干复跑           1 3 4 5
────────────────────────────────────────────────────────────────────────
 线上工时合计 5h48（含复核）；我这边任务书、验收、合并共 2h13；并行 3 条 Codex 线；关键路径 2 → 3 → 5 → 6

 额度：Codex 本周预计 9% → 约 21%

```

「预计完成」是该件验收完的时刻（含复核和 Argo 验收、合并）；「预估」是执行线的墙钟时间。关键路径里常有 Argo 自己这条线（任务书、验收、合并串行），所以六条线并行时完工时刻比「最长那条线」晚一个多小时是正常的。排期脚本的用时来源和置信度规则在 `estimates.md`。

## 执行中进度（只在四种情况出一次，只写变了的）

```

 第 5 件完（预估 13 分，实际 11 分）。第 3 件到第 3/5 项。第 1 件在第 4 项上失败两次，再失败一次就停、只把没过的项交 Astra · 很高补全。
 预计完工 19:24 → 19:50（第 1 件拖了）。Codex 本周 9% → 13%。
```

额度降档也在这里报一行，写法固定：「Codex 本周到 85%，第 1、6 件从 Astra 降到 6.1 Sol · 高，预计完工推到 21:00；想保质量就刷一张重置卡（还有 1 张），说一声我换回来。」质量优先下不自动降，改成问：「Codex 到 85%，按质量优先我不降型号。三选一：刷重置卡 / 等 10-22 15:50 重置 / 这两件降到 6.1 Sol · 高。」
