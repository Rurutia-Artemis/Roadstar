# R6 编程类 AI 任务用时数据（Grace，查证 2026-10-16）

原则：只收有出处的公开数据；区分「人类基线时长」与「模型/agent 墙钟」。

## 结论
1. METR 时间跨度度量的是「人类专家完成同类任务要多久」上模型 50% 成功点，不是模型跑了几分钟；TH1.1 任务池 228 题，31 题估 ≥8h，仅 5 题有实测人类基线。
2. Vals 的 SWE-bench / Terminal-Bench 给 agent 墙钟（每题平均）：短改动级 SWE 常见 3–14 分钟；TB4 长程终端任务常见 30 分钟到 2 小时以上（上限 8h）。
3. 按「小改动 / 页面实现 / 修 bug / 跨模块重构」切分的时长分布没有公开数据；只有难度桶（SWE：<15m / 15m–1h / 1–4h / >4h）和 TB4 领域分类可作近似。

## METR（metr.org/blog/2026-1-29-time-horizon-1-1；metr.org/time-horizons，2026-09-08 起不再积极更新）
任务池 228；估 ≥8h 的 31 题（TH1 为 14），其中 5 题有人类实测基线；以软件工程、ML、网络安全为主。
P50 时间跨度（人类时长尺度）：Opus 4.5 320 min [170, 729]；GPT-5 214 min [117, 480]；o3 121 min [74, 201]；Opus 4 101 min [58, 170]；Opus 5.x / GPT-6 / Grok 4.7 未公开。METR FAQ：AI 成功时通常比人类快数倍，不报告精确墙钟。
