# R5 同类产品多模型分配（Grace，查证 2026-10-16）

## 结论
1. 内容感知路由已成主流：OpenRouter Auto、Cursor Router、Copilot Auto、Not Diamond 都按任务类型/难度选模；LiteLLM 主做部署级负载均衡。
2. 质量/成本/速度档位普遍暴露：OpenRouter cost_tier（low→max）、Cursor Cost/Balance/Intelligence、Copilot Efficiency/Balance/Intelligence、Not Diamond tradeoff=cost|latency|quality。
3. 预估任务用时极少公开：多数产品不展示「预计几分钟完成」，展示的是选中型号、成本档、折扣或相对满意度。

## 值得 Roadstar 抄的三个做法
1. 显式 cost/quality 档位 + 默认偏省：用户只选策略，不选具体型号。
2. 难度二段式：先判简单再选 frontier；用提升幅度阈值避免无意义升级。
3. 回显实际选用模型 + 会话粘性：可审计、可复现，多轮不无故换模。
