# R3 订阅额度规则（Grace，查证 2026-10-16）

## 结论
1. Claude Max（5x=$100 / 20x=$200）：官方明确有滚动 5 小时 session 窗 + 按账户固定时刻重置的周窗；Max 为 Pro 每 session 额度的 5×/20×。Fable「最多用到周额度一半」有官方帮助中心出处（与其它型号共用同一周池）。
2. ChatGPT Plus/Pro × Codex：官方确认 5 小时窗 + 周窗（Plus 两者皆有；Pro 100/200/500 当前无 5 小时限制但仍有 included usage）。Instant reset（付费即时重置）与 banked reset（赠送可存重置）均有帮助中心专文；credits 为额度用尽后的按量加购，单位 credits/1M tokens。
3. Grok（The X Subscription）：共享周用量池（Grok + Cursor 一方席位），Plus 为基准，Premium≈4×、Super≈15×、Ultra≈50×；查剩余：Settings → Usage（百分比）。未找到绝对 token 上限，也未找到 CLI 查余量命令。

### 重置卡
官方叫 instant reset（付费）与 banked reset（赠送可存）。
- Instant reset（help.openai.com/en/articles/20001507）：购买后立即恢复 5 小时 + 周两边额度至满；是把正常周额度提前拉来，不是另加；不能存着用；新的周周期从重置后下一次请求起算，下次自动重置 = 那次请求后 7 天；仅合格 Plus/Pro 个人账户；入口 Settings → Usage「Buy an instant reset」或触达周限额后的 banner。美元标价未公开（见结账页）。
- Banked reset（help.openai.com/en/articles/20001498）：促销赠送的一次性重置，存在账户上直至使用或过期；不是现金或 API credits；Settings → Usage →「1 reset available / Full reset」；Full banked reset 刷新 5 小时 + 周窗，并改写下周重置日；只有真的刷新了至少一个窗才消耗。示例：2026-09-03/04 合格 Plus/Pro/Business 获赠；2026-09-07 为全局自动重置（不显示为 banked）。
