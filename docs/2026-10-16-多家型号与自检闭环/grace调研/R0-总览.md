# R0 Roadstar 1.12 调研总览（Grace，2026-10-16）

来源：Google Drive「Grace × Cloud 交接」，Grace 交回的 Google Doc，2026-10-16 由 Claude 原文转存。查证日期 2026-10-16。

## 三行结论
1. 本轮新交：R5（多模型分配）、R2（评测排名）、R4（查余额接口）、R6（编程任务用时）四份；R1/R3 沿用既有结果，未重做。
2. 可产品化信号：多模型路由普遍有 cost/quality 档位；评测上 TB4/AA 比已饱和的 SWE 更能分出 5.x/6.x；余额 API 国产与 DeepSeek/Moonshot/xAI 较齐，Anthropic/OpenAI 偏 Admin 用量而非余额。
3. 共性缺口：任务墙钟预估、型号扣额度倍数、METR 对最新型号、SWE 对新一代模型多为「未找到/未上榜」。

## 交叉建议（给 Roadstar 产品）
1. 路由 UX：抄 Cost/Balance/Intelligence 三档 + 回显实际模型（R5）。
2. 模型货架：优先看 TB4 + AA，勿只盯 SWE（R2）。
3. 余额面板：DeepSeek/Moonshot/xAI Management/MiniMax Plan 可直连；Anthropic/OpenAI 用 Admin 成本曲线代替「余额」（R4）。
4. 用时预估：公开数据不足以支撑细粒度 ETA；可先用 SWE 难度桶 + TB4 领域作粗档（R6）。
