# R4 查余额 / 用量接口（Grace，查证 2026-10-16；仅文档调研，未试调）

## 结论
1. 能直接查余额：DeepSeek /user/balance、Moonshot /v1/users/me/balance、xAI Management prepaid/balance；MiniMax Token Plan /v1/token_plan/remains（订阅 Key）。
2. 只能查历史用量/成本、没有实时余额：Anthropic Admin Usage + Cost；OpenAI Admin organization costs/usage。
3. 百炼余额走阿里云 BSS QueryAccountBalance；智谱公开的是 Coding Plan 配额接口，不是通用余额。
